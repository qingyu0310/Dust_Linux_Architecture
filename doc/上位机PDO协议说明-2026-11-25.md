# 上位机 PDO 协议说明（EtherCAT，双向 256 B）

日期：2026-11-25。面向主站（Linux + SOEM）实现，对应从站代码：`project/thread/ecat/pdo_layout.hpp`、`trd_ecat.cpp`。

## 1. 总览

| 项 | 值 |
| --- | --- |
| 传输 | EtherCAT 周期 PDO |
| 周期 | 1 ms |
| RxPDO（主站 → 从站） | 线上 256 B，主站映射前 44 B |
| TxPDO（从站 → 主站） | 线上 256 B，主站映射前 156 B |
| 字节序 | 小端（x86 与 RISC-V 均为 LE） |
| 对齐 | 全部 `packed`，1 字节对齐、无填充、无预留字段 |
| 浮点 | IEEE-754 binary32 |
| 版本 | `proto_major=1`，`proto_minor=0`，`slot_map_version=2` |

结构体只声明实际使用的字段；线上帧固定 256 B，主站结构之外的字节由 IOmap 保持全零，从站不使用。

## 2. TxPDO：从站 → 主站

| 偏移 | 内容 | 字节 |
| ---: | --- | ---: |
| 0 | FeedbackHeader | 30 |
| 30 | RemoteFeedback | 28 |
| 58 | ImuFeedback | 50 |
| 108 | 电机反馈区（4 槽 × 12 B） | 48 |
| 156 | 线上保持零（主站不映射） | 100 |

### 2.1 FeedbackHeader（偏移 0，30 B）

| 偏移 | 字段 | 类型 | 语义 |
| ---: | --- | --- | --- |
| 0 | magic | u32 | 固定 `0x31424450`（ASCII "PDB1"，按小端读为字节 `50 44 42 31`） |
| 4 | proto_major | u16 | 1 |
| 6 | proto_minor | u16 | 0 |
| 8 | mcu_boot_id | u32 | 每次上电重新生成；主站据此判断从站是否重启 |
| 12 | feedback_seq | u32 | 每 1 ms 自增，溢出回绕 |
| 16 | mcu_tick_us | u32 | 本帧组帧时刻，MCU 本地 µs |
| 20 | applied_command_seq | u32 | 已执行的 `command_seq`（无执行器时恒 0） |
| 24 | accepted_host_session | u16 | 当前被接纳的主机会话号；0 = 无有效会话 |
| 26 | status_flags | u16 | bit0：已接纳会话（`accepted_host_session != 0`） |
| 28 | fault_code | u16 | 故障码；0 = 正常 |

**判断从站重启**：`mcu_boot_id` 与上一帧不同 → 从站重启，主站必须重新取 boot_id、重新建立会话。

### 2.2 RemoteFeedback（偏移 30，28 B）

| 偏移 | 字段 | 类型 | 语义 |
| ---: | --- | --- | --- |
| 30 | source_seq | u32 | 遥控消息帧序号，来自从站内部 `version`；每解析一帧自增 |
| 34 | sample_tick_us | u32 | 该帧的**采样时刻**（MCU 本地 µs），不是 PDO 组帧时刻 |
| 38 | axis[0] | f32 | chassisx，归一化 [-1, 1] |
| 42 | axis[1] | f32 | chassisy，归一化 [-1, 1] |
| 46 | axis[2] | f32 | yaw，归一化 [-1, 1] |
| 50 | axis[3] | f32 | pitch，归一化 [-1, 1] |
| 54 | controls | u16 | 开关位，见下表 |
| 56 | protocol | u8 | 0 = 未报告 |
| 57 | status | u8 | bit0：已收到过有效遥控帧（失联请用 sample_tick_us 的 age 判断） |

`controls` 位定义（1 = On / Spin）：

| 位 | 含义 |
| ---: | --- |
| 0 | robot_ctrl 整车总开关 |
| 1 | chassis_mode = Spin（0 = Normal） |
| 2 | shoot_ctrl |
| 3 | reload_ctrl |
| 4 | autoaim_ctrl |
| 5 | supercap_ctrl |
| 6–10 | custom1–custom5 |

**新鲜度**：`age_us = (now_us − sample_tick_us) mod 2^32`。遥控帧率约 70–100 Hz，1 ms PDO 会连续多拍携带同一 `source_seq`，属正常；`source_seq` 不变且 `age_us` 持续增大时按失联处理。

### 2.3 ImuFeedback（偏移 58，50 B）

| 偏移 | 字段 | 类型 | 语义 |
| ---: | --- | --- | --- |
| 58 | source_seq | u32 | IMU 姿态消息帧序号，每解算一帧自增 |
| 62 | sample_tick_us | u32 | 该帧的采样时刻（MCU 本地 µs） |
| 66 | quaternion[0..3] | f32 ×4 | w, x, y, z |
| 82 | gyro[0..2] | f32 ×3 | rad/s |
| 94 | accel[0..2] | f32 ×3 | m/s² |
| 106 | flags | u16 | bit0：已产生过姿态（`source_seq != 0`） |

从站已在下位机完成静态零偏与安装轴处理，主站**不要重复**做这两件事。

### 2.4 电机反馈区（偏移 108，48 B）

4 槽 × 12 B，每槽一个电机（槽位 0~3 = 四个 C620）。主站实现见 `framework/topic/ecat_chassis/ecat_chassis.hpp`，从站未实现时全零。

| 槽内偏移 | 字段 | 类型 | 语义 |
| ---: | --- | --- | --- |
| 0 | id | u16 | 槽位号 0..3 |
| 2 | status | u16 | bit0=在线；bit1=故障 |
| 4 | omega | f32 | 轮角速度 rad/s（从站已换算到轮侧） |
| 8 | current | f32 | 实际电流 A |

## 3. RxPDO：主站 → 从站

| 偏移 | 内容 | 字节 | 本版 |
| ---: | --- | ---: | --- |
| 0 | CommandHeader | 36 | 解析 |
| 36 | 电机命令区 | 8 | 见 §3.2 |
| 44 | 线上保持零（主站不映射） | 212 | 从站不使用 |

### 3.1 CommandHeader（偏移 0，36 B）

| 偏移 | 字段 | 类型 | 主站要求 |
| ---: | --- | --- | --- |
| 0 | magic | u32 | 必须 `0x31434D43`（ASCII "CMC1"） |
| 4 | proto_major | u16 | 1 |
| 6 | proto_minor | u16 | 0 |
| 8 | byte_length | u16 | 必须 256（线上帧长） |
| 10 | slot_map_version | u16 | 必须 2 |
| 12 | host_session | u16 | 主机会话号；同一会话生命周期内保持不变 |
| 14 | command_seq | u32 | 只有产生新决策时才自增；重复发送同一命令不得自增 |
| 18 | mcu_boot_id_echo | u32 | 必须回显最近一次从 TxPDO 读到的 `mcu_boot_id` |
| 22 | feedback_seq_echo | u32 | 本命令依据的 `feedback_seq` |
| 26 | lease_us | u32 | 租约上限（µs），从站侧再夹一层 |
| 30 | compute_time_us | u32 | 主站控制计算耗时，诊断用 |
| 34 | flags | u16 | bit0 请求 arm；bit1 请求 disarm |

### 3.2 电机命令区（偏移 36，8 B）

C620 电流控制帧（CAN 0x200）的数据段，从站收到后**原样转发到 CAN**。主站未启用控制时清零，命令停更超过 100 ms 也清零。主站实现见 `framework/topic/ecat_chassis/ecat_chassis.hpp`。

| 区偏移 | 内容 | 类型 | 语义 |
| ---: | --- | --- | --- |
| 36 | 0x200 数据段 | u8[8] | 4 × int16 电流原始值，小端，依次对应 CAN ID 0x201~0x204 |

电流换算：`raw = current(A) × 819.2`（±16384 ↔ ±20 A），越界按 ±16384 饱和。

### 3.3 从站校验规则（当前实现）

1. 只有新帧才处理：`SM2` 收帧计数变化视为新命令；重复读同一帧不刷新时间戳。
2. 整帧拒绝条件（任一不满足）：
   - `magic != 0x31434D43`
   - `byte_length != 256`
   - `slot_map_version != 2`
   - `mcu_boot_id_echo != 从站当前 mcu_boot_id`
   - 从站不在 OP 状态
3. 通过后：`accepted_host_session = host_session`，记录 `command_seq` 与接收时刻。
4. 掉 OP 或超过 100 ms 无新帧：`accepted_host_session = 0`，`status_flags.bit0` 清零。
5. 电机命令区由从站转发到 CAN 0x200；线上帧其余字节不使用。

### 3.4 推荐主站时序

1. 进入 OP，读取 TxPDO，校验 `magic`/`proto_major`，记录 `mcu_boot_id`。
2. 选择 `host_session`（非 0，建议随机或递增）。
3. 每个周期填前 44 B（命令头 + 电流帧）；`command_seq` 仅在新决策时 +1；`mcu_boot_id_echo` 每周期回显。
4. 观察 TxPDO 的 `accepted_host_session == host_session` 与 `status_flags.bit0` 确认为已接纳。
5. 退出/崩溃前不做特殊清理；从站靠 100 ms 心跳/停更自行清除会话。

## 4. 通用规则

- **时间**：所有 `*_tick_us`/`mcu_tick_us` 都是 32 位 µs 计数，约 71.6 分钟回绕；**比较一律用模差** `(a - b)`，不要直接比大小。
- **序号**：`feedback_seq`、`source_seq`、`command_seq` 都是 32 位回绕计数，只用于判断"是否更新"，不做绝对比较。
- **帧长**：线上帧固定 256 B；主站结构只映射前 156 B（Tx）/ 44 B（Rx），其余字节保持零，从站不使用。
- **版本升级**：任何字段增删或偏移变化都要提升 `proto_major` 或 `slot_map_version`，不允许长度不变时悄悄换布局。

## 5. 主站侧结构体参考（C/C++）

```c
#pragma pack(push, 1)

typedef struct { uint32_t magic; uint16_t proto_major, proto_minor; uint32_t mcu_boot_id;
    uint32_t feedback_seq, mcu_tick_us, applied_command_seq;
    uint16_t accepted_host_session, status_flags, fault_code; } feedback_header_t;

typedef struct { uint32_t source_seq, sample_tick_us; float axis[4]; uint16_t controls;
    uint8_t protocol, status; } remote_feedback_t;

typedef struct { uint32_t source_seq, sample_tick_us; float quaternion[4], gyro[3], accel[3];
    uint16_t flags; } imu_feedback_t;

typedef struct { uint16_t id, status; float omega, current; } motor_feedback_t;

typedef struct { feedback_header_t header; remote_feedback_t remote; imu_feedback_t imu;
    motor_feedback_t motor_feedback[4]; } tx_pdo_t;

typedef struct { uint32_t magic; uint16_t proto_major, proto_minor, byte_length, slot_map_version,
    host_session; uint32_t command_seq, mcu_boot_id_echo, feedback_seq_echo, lease_us,
    compute_time_us; uint16_t flags; } command_header_t;

typedef struct { command_header_t header; uint8_t motor_command[8]; } rx_pdo_t;

#pragma pack(pop)

_Static_assert(sizeof(tx_pdo_t) == 156, "tx pdo");
_Static_assert(sizeof(rx_pdo_t) == 44, "rx pdo");
_Static_assert(sizeof(feedback_header_t) == 30, "header");
_Static_assert(sizeof(remote_feedback_t) == 28, "remote");
_Static_assert(sizeof(imu_feedback_t) == 50, "imu");
_Static_assert(sizeof(motor_feedback_t) == 12, "motor feedback");
_Static_assert(sizeof(command_header_t) == 36, "cmd header");
```
